# InnovateX 2026

A responsive fictional college festival website built from scratch using HTML, CSS, and vanilla JavaScript.

## Features
- Hero section with a live JavaScript countdown to December 18, 2026, 9:00 AM (visitor's local time)
- About section
- Five expandable event cards
- Interactive three-day schedule
- Responsive image gallery
- Registration form with client-side validation and success feedback
- Contact details and social media links
- Mobile navigation and responsive layouts

## Run locally
1. Download or clone the repository.
2. Open `index.html` in your browser (or use VS Code Live Server).
3. No build tools or JavaScript libraries are required.

## Important demo notes
- Registration is **front-end only**. It does not save or send registration data.
- Fest, venue and contact address are fictional. Replace them with real details if needed.
- Gallery images are illustrative and loaded from Unsplash; internet access is required to display them.
- Fonts are loaded from Google Fonts, with local fallbacks.
- Countdown uses the visitor's local timezone.

## Suggested GitHub commit sequence
Make these commits yourself as you develop and test the site:
1. `Initial HTML structure and navigation`
2. `Add responsive styling and hero section`
3. `Build event cards and schedule interaction`
4. `Add gallery and registration validation`
5. `Polish mobile layout and documentation`

## Deployment
In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Your public URL will be shown after deployment.
