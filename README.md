# 🚀 INNOVATEX 2026

### Imagine. Invent. Ignite.

INNOVATEX 2026 is a modern, responsive, and interactive website designed to showcase innovation, creativity, technology, and fresh ideas.

The project focuses on delivering a visually appealing user experience with a clean interface, smooth navigation, and modern web design principles.

## ✨ Features

- 🎨 Modern and attractive user interface
- 📱 Responsive website layout
- 🧭 Clean and user-friendly navigation
- ⚡ Interactive elements using JavaScript
- 💻 Organized and maintainable code
- 🌐 Built using core web technologies

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, and responsiveness
- **JavaScript** – Interactive functionality
- **VS Code** – Code editor
- **Git & GitHub** – Version control and project hosting

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/SIAGOEL/INNOVATEX.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in your web browser to explore the website.
